# 星屿用户端样式

布局参考 [聚盟云](https://jujiasu.com)，只参考样式，功能仍以 Xboard 为准。品牌、文案和配图都是星屿自己的，没有照搬参考站的图片、Logo 或文案。业务界面仍是 Xboard 原编译产物 `assets/umi.js`，没有重写登录、支付、订单、订阅或工单接口。

## 文件

- `theme/Xboard/landing.blade.php`：访客首页，自带一份深色样式。
  - 结构参考聚盟云：顶栏、左文右图首屏、热门订阅计划表、注册引导、2×2 服务说明、日美节点评分、客户端下载、邀请返佣与 Telegram、发光收尾区和三栏页脚。
  - 套餐表读取 `/api/v1/guest/plan/fetch`，各列含义如下：
    - 流量：`transfer_enable`。
    - 速度：`speed_limit`，为空时显示「不限速」。
    - 设备数：`device_limit`，为空时显示「不限设备数量」。
    - 价格：第一个有价格的周期。
    - 「立即购买」：进入 `#/plan/{id}`。
  - 不虚构折扣或周期。手机端套餐表会变成卡片。
- `theme/Xboard/console.blade.php`：控制台（原 SPA）的样式层，只有 CSS。
  - 实现方式：仍是覆盖 Naive UI 类名和组件变量的 CSS。仓库里只有编译后的 `umi.js`，没有前端源码，所以只能这样改。
  - 外观：白色侧栏加分组菜单，选中项为浅蓝底蓝字；浅灰内容区；白卡片用细边框、不加阴影；主色 `#165dff`。
  - 没有背景图的公告轮播会显示深色星空底。
  - 深色模式跟随 Xboard 原有开关。
  - 首页和 `dashboard.blade.php` 都加载这一份，所以从首页进入 `#/login` 时，登录页样式与控制台一致。
- `theme/Xboard/console-dashboard.blade.php`：仪表盘区块，由 `console.blade.php` 引入，只在 `#/dashboard` 生效。
  - 在公告轮播下面插入一行三张卡：蓝色「我的订阅」（套餐、到期、流量进度、续费、复制订阅链接；无套餐时显示「购买订阅」）、「流量使用」（上行、下行、总计）、「我的邀请」（人数、佣金比例、可用佣金）；下面是「客户端下载」四个入口。原「捷径」列表改成左侧蓝条的操作行。
  - 数据用当前登录 token 读取 `user/getSubscribe` 和 `user/invite/fetch`，只读，每次进入仪表盘读一次。
  - 读取成功后才隐藏原「我的订阅」卡；读取失败时不插入，原卡照常显示。邀请数据读不到时只在卡里提示，不影响其他区块。
  - 原卡按标题文字识别（简体、繁体、英文）。换成其他语言时原卡不会被隐藏，会和新卡同时出现。
- `theme/Xboard/dashboard.blade.php`：已登录入口。保留登录态 cookie 同步和客户端下载悬浮按钮，按钮和面板改为控制台配色。顶部 TRIALUP8 倒计时活动条已移除：你要求首页顶部不显示活动后，Codex 把控制台里的这条也一并删了。如需在控制台保留，可以从 git 恢复。

上一版的苹果风视觉层 `appearance.blade.php`、导航折射效果 `glass.blade.php`，以及 Codex 往每个控制台页面插入标题和欢迎区的脚本，均已删除。

## 本地预览

```text
npm ci
npm run preview:theme
```

- 访客首页：`http://127.0.0.1:4186`。
- 演示控制台：`http://127.0.0.1:4186/?demo=1#/dashboard`。

预览直接读取当前 Blade 模板，以演示数据代替后端；所有写入接口都会被拒绝。修改模板后刷新即可看到变化；只改 hash 不会重新加载样式，需要整页刷新。修改 `scripts/preview-theme.mjs` 后需要重启预览服务。

## 自动检查

```text
npm run test:theme
```

共 11 项，覆盖以下内容：

- CSS 与脚本语法。
- 首页基础样式不压过组件间距：带 `#sl-landing` 的清零和基础规则必须包在 `:where()` 里，否则按钮、卡片、标题的内外边距会被清成 0。
- 套餐表的真实价格：零价和非月付周期。
- 速度和设备数的空值显示。
- 购买链接。
- 名称与说明转义。
- 接口空数据和失败时的提示。
- 页内路由启动 SPA，且不伪造登录 cookie。
- 已有 token 时直接进入。
- 控制台样式层不含脚本。
- 仪表盘区块：真实数据显示、无套餐状态、读取失败时保留原卡、套餐名转义、请求带登录 token。

## 发布前仍需验证

本机没有 PHP，因此没有做过 Laravel/Blade 实际渲染，也没有和真实后端联调。请在测试环境核对：

1. 未登录首页、登录、注册、找回密码；已登录时直接进入仪表盘。
2. 仪表盘区块的数据是否与原卡一致（到期日、流量、佣金单位）；仪表盘、套餐及详情、节点、订单及付款回跳、邀请、个人中心、流量、知识库、工单。
3. 390px 手机、768px 平板、1440px 桌面；侧栏折叠、深色模式、弹窗、第三方客服浮窗。
4. 控制台样式依赖 Naive UI 类名和 `.cus-scroll-y` 容器。升级 `umi.js` 后需要回归检查。
